# 原作与第三方说明

## kigumi 视觉与代码来源

项目整理前的 README 与页面署名记录：本项目改编自 FUJI（吉藤智広）的「日本建築 立体木組み図 kigumi v8.9」，原作入口为 https://re-presentation.jp/lab.html 。页面继续保留原作者链接与署名。

沿用的内容包括铅笔排线、淡彩表现、纸面装饰、自下而上搭建、剖切及注记相关实现。中国建筑的程序化模型与中文页面是在此基础上的改编。
